# Software Factory

If you are the coordinating session in the user's terminal (you write Task files, start factory
jobs, open and merge pull requests), read [docs/runbooks/coordinator.md](docs/runbooks/coordinator.md)
first: it holds the user's working rules.

If you are a factory job (Implementer, Claude review, Codex gate, Task check), ignore that runbook
and follow `factory/HANDBOOK.md` and your Task file.
